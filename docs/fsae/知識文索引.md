# 知識文索引 — code 即教材 (FSAE 取向)

這個專案除了是賽車調校模擬器，也刻意被寫成**可以「讀 code 學工程」的教材**。
程式碼裡埋了一系列「知識文」——不是普通註解，是寫給 FSAE / 賽道新手工程師看的小課。
每一篇都用同一個格式，講清楚「直覺 → 物理 → 公式 → 對應到哪段 code → FSAE 注意 → 延伸」。

## 怎麼用

- **想學物理**：照下面的學習路徑，一篇一篇讀。每篇旁邊就是「真的在跑」的程式碼，
  讀完馬上看到公式怎麼變成 code、code 又怎麼變成模擬器上的數字。
- **想找某篇**：在 repo 搜尋 `知識文 #編號`。
- **想驗證自己懂了**：去模擬器調對應的參數(ARB、配重、胎…)，看數字往哪邊動，
  和知識文講的方向對不對。

## 學習路徑

| # | 主題 | 在哪 (檔案 / 函式) | 程度 |
|---|---|---|---|
| 1 | 車為什麼推頭/甩尾？輪胎負載敏感度 | `renderer/js/dynamics-model.js` → `axlePairCorneringStiffness` | ★★☆ |
| 2 | 側傾剛性怎麼算、ARB 為什麼是調平衡主力 | (規劃中) `rollStiffnessSpring` | ★★☆ |
| 3 | LLTD：幾何 vs 彈性荷重轉移、Roll Center | (規劃中) Tier1 LLTD 分解 | ★★★ |
| 4 | Ride frequency 與 flat ride（Olley） | (規劃中) ride frequency | ★☆☆ |
| 5 | 阻尼比 ζ：為什麼是 2√(km)、F-V 曲線怎麼讀 | (規劃中) damping ratio | ★★☆ |
| 6 | 車高 → 空力地圖：高速下壓力怎麼來的 | (規劃中) 空力 / 麗寶 ClA | ★★★ |
| 7 | 輪胎工作窗口：胎溫/胎壓甜蜜點 | (規劃中) `LihpaoStintSim` | ★★☆ |

## 知識文格式（寫新篇時照這個）

```
/*
╔════════════════════════════════════════════════════════╗
║  知識文 #N — 標題                                       ║
║  對象：…   程度：★★☆   閱讀時間：N 分鐘                 ║
╚════════════════════════════════════════════════════════╝
【一句話】     一句講完這篇的核心
【直覺】       先打掉常見誤會，用生活/賽道語言建立畫面
【物理】       為什麼會這樣，機制
【公式】       關鍵式子 + 出處
【對應到 code】 哪個變數對應物理的哪一塊
【FSAE 注意 ⚠】 FSAE 車和量產/職業車的差異、最常犯的錯
【延伸】       教科書章節、下一篇
*/
```

## 原則（為什麼這樣做）

- **code 是最誠實的教材**：公式寫錯，模擬器數字就錯，騙不了人。知識文 + 可跑的 code +
  迴歸測試，三者互相驗證，學生學到的是「對的、而且自己能驗證」的東西。
- **方法論可搬，數值不可搬**：FSAE 車和這些職業車差很遠，知識文的重點永遠是
  「為什麼這樣想」，不是「照抄這個數字」。每篇的「FSAE 注意」就是在守這條線。
- **降低門檻**：學生不用先看得懂日文設定表、不用有 Tomcat/WinDarab，
  讀中文知識文 + 在模擬器上玩，就能建立職業級的物理直覺。
