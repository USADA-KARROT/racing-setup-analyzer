# R3.0B — Analysis Case Library & Local Persistence

Makes an Analysis Case a **persistable, reopenable, duplicable, archivable** local-first engineering record. Browser
and Electron share ONE contract (IndexedDB); no cloud, no accounts. Raw telemetry stays local-only and never leaves
in a portable export.

## Modules (pure / UMD; Node-testable via an injected in-memory backend, never real IndexedDB)
- **storage-backend.js** — namespaced async KV: `get / put / add (create-if-absent) / del / list / estimateBytes /
  update(ns,key,fn)` and an IndexedDB-safe atomic **`transact({stores, reads, compute})`**: all reads are declared
  up front, `compute(readValues)` is **synchronous and pure** and returns the writes + a result, applied in ONE
  `readwrite` transaction (commit-or-abort; quota → typed `STORAGE_QUOTA_EXCEEDED`). `MemoryBackend` (tests/SSR;
  global mutex + structured-clone at every boundary) and `IndexedDBBackend` (browser + Electron). A renderer never
  silently falls back to memory — unavailability surfaces `STORAGE_UNAVAILABLE`.
- **schema-migration.js** — `migrateCaseRecord / migrateSessionRecord`: a FUTURE schema version is **rejected
  fail-closed** (never coerced); older versions migrate step-by-step; unknown fields are preserved in the local
  record (never silent-dropped); deterministic, logged.
- **case-record-schema.js** — `sanitizeForStorage` (LOCAL, all-or-nothing: JSON-safe; reject cyclic/non-plain/
  function; every array ≤ 256, depth ≤ 12, size-bounded — so raw telemetry can never be stored even locally; if any
  node violates, the save is **rejected**, never lossily stored) + `toPortableBundle` / `validatePortableBundle`
  (PORTABLE: a curated, strictly-allowlisted, **value-constrained** closed schema — enum vocabularies, code/id
  patterns, length caps; only enumerated bounded code arrays; any off-allowlist or constraint-failing field is
  EXCLUDED + logged; required fields validated; a future bundle version is rejected fail-closed).
- **case-store.js** — `createCaseStore(backend)`: `create / save / open / duplicate / archive / unarchive /
  remove(confirm:true) / list / exportCase / importBundle / compact`. Every mutation is ONE atomic `transact` over
  [cases, caseIndex] (payload + index committed together — no two-phase window, no overwrite/dangling races).
  `save`-update requires an existing entry (a deleted case is **not** resurrected); `create` aborts on id
  collision; `delete` is fail-closed without `confirm:true`. `duplicate` deep-clones (no shared refs, fresh id).
- **session-store.js** — telemetry sessions in a SEPARATE namespace; raw telemetry is local-only, **byte-bounded**
  (`maxSessionBytes` / `maxRawBytes`, oldest-evicted with a bounded eviction log embedded in the index envelope →
  index/log can't diverge), never auto-uploaded, never in a portable case bundle. `exportRawArchive(id)` is an
  explicit opt-in, distinct from the case export.
- **case-library-viewmodel.js** — pure `buildCaseLibraryView`: search + vehicle/track/date/status filters,
  pinned/archived/recent buckets, and per-case telemetry/calibration/corner indicators read from the STORED
  evidence (never re-decided).

## LOCAL fidelity vs PORTABLE safety (the decisive split)
- A **local record** holds the full sanitized analysis view model → `save → reopen` is **identical** (results +
  trust metadata, including `observation.blockedReasons`, restored exactly). Boundedness is proven by the universal
  array/depth/size cap, not by enumerating the view model.
- A **portable bundle** is a curated, strictly-allowlisted, value-constrained subset — provably free of raw
  telemetry sample arrays and large free-form payloads. An **imported** bundle is stored as an explicitly degraded
  `imported_summary` (badged "full section detail not included; re-run locally for detail") and is **never** promoted
  to a full local analysis.

## UI
The Analysis Cases section is a real **Case Library**: list + search/filters + pinned/archived/recent, with Save /
Save as new / Open / Duplicate / Archive / Delete (confirm) / Export / Import and a debounced **autosave** toggle
(autosave only ever *updates* an already-saved `local_full` case — it never auto-creates a case and never touches an
imported summary). An **imported summary** opens into a dedicated, explicitly-degraded view (the full analysis
workspace is gated off so it can't dereference the curated bundle's missing section objects). A future-schema
record is rejected by both `open` and `save` (a newer record is never silently clobbered with an older one). Raw
telemetry working state (`lastSession`, `importedBundle`, …) was moved OUT of the Alpine reactive tree into a
non-reactive `caseDataHolder`, so no raw sample array lives in the reactive tree. Storage failures surface a
readable error.

## Honesty boundaries
Persistence stores/restores the services' outputs; it never recomputes physics or re-decides eligibility (the
library indicators read stored evidence). Migration never silent-drops; future versions fail closed. Raw telemetry
is local-only, bounded, never portable, never auto-uploaded. Imported cases are explicitly degraded, never
misrepresented as full local analyses.
