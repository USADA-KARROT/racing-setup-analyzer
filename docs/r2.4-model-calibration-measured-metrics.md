Turns R2.3's DEFERRED calibration capability into honestly-gated MEASURED metrics, on the SAME
`runAnalysisWorkspace` pipeline (no real-only/demo-only path). The frozen yaw engine, the physics model, and
the presets are NOT modified — measured K_us is pure downstream arithmetic over the engine's per-bin output.


## Measured K_us method (downstream of the frozen yaw engine)
Bicycle model `1/G = L/V + K·V`, with **L = wheelbase FIXED** (authoritative resolved input — never fitted),
`G` = road-wheel yaw gain (rad/s per road-wheel rad), `V` = bin midpoint speed. Per bin, per direction:
`K_i = (1/G_i − L/V_i)/V_i` → `K_deg_per_g = K_i · g · 180/π`. `G_i` comes from the engine's existing
direction-split `yawPerSteerStats.median` divided by the verified steering ratio.

**Statistical fit is necessary but NOT sufficient.** A measured K_us is emitted only when ALL hold: positive
gain (`G>0`); ≥3 usable bins per direction (≥5 samples each); ≥8 m/s speed span; robust across-bin
consistency (`MAD/|median| ≤ 0.5`, guarded); a weak R² floor; **per-direction agreement** (left vs right
within tolerance, never folded by |abs|); and a plausible band (−5…12 deg/g). Any failure → `available:false`
+ an explicit reason (no number emitted). Even when produced it is `Measured (kinematic, confounded)` and
always carries systematic-confounder limitations (tyre load sensitivity, aero, transient-vs-steady-state,
single session, fixed-ratio assumption).

## Calibration contract
- The `steering_ratio` calibration's `value` is **road-wheel radians per one PROJECTED engine-steer unit**
  (the steering value AS the yaw engine consumes it, after `{scale,offset,sign}`). Dividing the engine's
  `yaw/projected_steer` median by it yields rad/s per road-wheel rad with no residual scale.
- Steering-bound calibrations (`steering_sign/zero/ratio`) carry a `channelBinding = {rawColumnId,
  projectionSignature}`. A calibration **holds** only if `verified ∧ session-applicable ∧ binding-matched`.
  Changing the steering mapping, unit, scale, offset, or sign invalidates it (stale → blocked). A calibration
  scoped to a different session never enables a measured result. Conflicting numeric values **fail closed**.
- `signedResponseEligible = steeringSign ∧ steeringZero holds`;
  `calibratedMagnitudeEligible = signedResponseEligible ∧ a single agreed finite>0 steering_ratio value`;
  `roadWheelMetricsEligible = calibratedMagnitudeEligible` (the canonical ratio is already road-wheel-referenced).

## Honesty boundaries (§10 / §19)
- **No steering calibration → no measured K_us** (§19-3). The directional R2.3 tendency stays
  calibration-INDEPENDENT and byte-identical; observation re-derives capability from evidence (a forged
  `advisory` flag changes nothing).
- **Insufficient/low-SNR data → blocked, not fabricated** (mirrors the real F3 finding that 20 Hz kinematic
  K_us is often not identifiable).
- **Provenance is machine-read, never assumed.** Sessions carry `dataProvenance`
  (`synthetic`/`real`/`unverified`, default unverified); measured output reflects the actual provenance and is
  never presented as validated-against-real unless provenance says `real`. Repo fixtures are synthetic.
- Directional ≠ measured; synthetic ≠ real; fit quality ≠ physical truth; correlation ≠ causation.
